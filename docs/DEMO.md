# Two-minute demo

Use only placeholder configuration and a local development account.

## Setup

- Start the local frontend and backend.
- Create a local test account, or use this placeholder:
  - Email: `demo-account-placeholder`
  - Password: `LOCAL-DEMO-PASSWORD-PLACEHOLDER`
- Upload two short, non-sensitive sample documents.

## Script

1. **0:00-0:15 — Introduce the problem.**
   "ClosedAI helps people search across their own documents without losing source context."

2. **0:15-0:35 — Upload documents.**
   Open the document library and upload a short PDF and text file. Point out processing status and the selected unit.

3. **0:35-0:55 — Ask a focused question.**
   Ask: "What are the main points, and what does each document say?"
   Explain that retrieval is scoped to the selected unit and authenticated user.

4. **0:55-1:15 — Follow up.**
   Ask: "Explain the first point in simpler terms."
   Show that conversation context is used in the follow-up.

5. **1:15-1:40 — Verify citations.**
   Open a cited source and point out its filename and page number. Distinguish retrieved evidence from general knowledge.

6. **1:40-2:00 — Show controls.**
   Briefly open usage and account settings. Explain that providers, credits, and data controls are configurable.

Do not use real production accounts or credentials in screenshots or recordings.
